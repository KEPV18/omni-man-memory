# 👥 Customer Tracker Skill

**Created:** 2026-04-11  
**Skill:** Track customer interactions

---

## 🎯 What I Do

Track all customer-related events:
- Complaints (F/09)
- Feedback (F/10)
- Corrective Actions (F/22)
- QA Requests (F/17)

---

## 📋 Forms to Use

| Event | Form | Code |
|-------|------|-------|
| Customer Complaint | F/09 | Track issue |
| Feedback Survey | F/10 | Satisfaction |
| Problem Found | F/22 | Fix action |
| Test Request | F/17 | Pre-delivery check |

---

## 🔄 Tracking Flow

1. **Complaint received** → Create F/09
2. **Investigate** → Document findings
3. **Fix** → Create F/22 if needed
4. **Verify** → Create F/17 if needed
5. **Close** → Update customer

---

## 📊 Customer Data

From F/09 (Complaint):
- Customer name
- Issue description
- Severity level
- Timeline
- Resolution

---

## 🎯 Automation

- Auto-create F/09 when "complaint" or "issue"
- Auto-create F/22 when "fix" or "corrective"
- Auto-create F/17 when "test" or "check"
